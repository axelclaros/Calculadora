# CALCULADORA CIENTÍFICA

## Reseña

Proyecto de una calculadora científica elaborada en Python por alumnos de la FNI, de las especialidades de Ingeniería de Sistemas e Ingeniería Informática.

El código se encuentra en el archivo calculadora.py y se irá ampliando con nuevas funcionalidades.

## Operaciones

Por ahora el archivo calculadora.py incluye las siguientes funciones:

- **Suma**: suma(a, b)
- **Resta**: resta(a, b)
- **Multiplicación**: multiplicacion(a, b)

```python
def suma(a, b):
    return a + b

def resta(a, b):
    return a - b

def multiplicacion(a, b):
    return a * b
```

Se añadirán más funciones en breve.

## Funcionamiento

1. Abrir una consola en la carpeta del proyecto.
2. Correr el programa:

```bash
python calculadora.py
```

3. Elegir la operación.
4. Ingresar los valores.
5. Recibir el resultado.
